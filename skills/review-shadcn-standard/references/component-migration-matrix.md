# Bảng Đối Chiếu & Migration 72 Thành Phần Chuẩn Shadcn UI

Tài liệu tham chiếu gốc (SSOT) cho kỹ năng `review-shadcn-standard`. Mọi thành phần giao diện trong hệ sinh thái Tuquet (`admin`, `lib`, `automa`, `tuquet.com`) bắt buộc phải tuân thủ 72 components chuẩn dưới đây.

## Chú giải Trạng thái Package
- **`@tuquet/vue-ui`**: Package thư viện UI trung tâm tại `lib/packages/vue-ui/src/components/ui/`.
- **`@vben-core/shadcn-ui`**: Package UI nội bộ tại `admin/packages/@core/ui-kit/shadcn-ui/src/ui/`.
- **Quy tắc khi thiếu Primitive (`[THIẾU PRIMITIVE]`)**: Nếu component mục tiêu chưa có sẵn trong package hiện tại của dự án đang kiểm định, Agent **bắt buộc đánh dấu `[THIẾU PRIMITIVE]` trong bảng báo cáo và hỏi ý kiến người dùng** trước khi port/thêm primitive mới vào package.
